🚀 ۱. چطور این سایت را روی یک دامنه رایگان لانچ کنید؟ (در ۳ دقیقه)

  1. یک اکانت رایگان در GitHub.com بسازید و یک مخزن (Repository) جدید به نام suithub-tr ایجاد کنید.
  2. همین فایل index.html (اپلیکیشن فعلی) را در مخزن گیت‌هاب آپلود کنید.
  3. روش اول (GitHub Pages): از منوی Settings مخزن وارد بخش Pages شوید و شاخه main را انتخاب کنید تا لینک رایگان دائمی https://username.github.io/suithub-tr فعال شود.
  4. روش دوم (Netlify / Vercel با دامنه اختصاصی رایگان): سایت app.netlify.com یا vercel.com را باز کنید، روی Import from GitHub کلیک کنید و مخزن خود را وصل کنید تا دامنه رایگان مثل suithub-tr.netlify.app یا suithub-tr.vercel.app با SSL رایگان به شما بدهد. هر مشتری که وارد این لینک شود، به صورت پیش‌فرض حالت مشتری را می‌بیند و فقط شما با زدن قفل بالا (رمز 1234) یا با آدرس ?admin=1234 به پنل مدیریت دسترسی دارید.

⏰ ۲. آپدیت خودکار هر شب ساعت ۱۲:۰۰ + افزودن خودکار محصولات جدید

فایل زیر را در مسیر .github/workflows/nightly_sync.yml در مخزن گیت‌هاب خود قرار دهید. سرور گیت‌هاب به صورت کاملاً رایگان هر شب راس ساعت ۱۲:۰۰ شب به وقت استانبول (cron: '0 21 * * *' معادل 00:00 TRT) بیدار می‌شود، هر ۵ سایت را اسکن می‌کند، قیمت‌های لیر را بروز می‌کند و اگر هر سایت محصول جدیدی اضافه کرده باشد، آن را با تگ «Yeni / جدید» و تمام عکس‌های اصلی‌اش وارد کاتالوگ می‌کند: 

name: Nightly 00:00 Istanbul SuitHub Sync

on:
  schedule:
    # Runs every day at 21:00 UTC = 00:00 Midnight Istanbul Time (TRT / UTC+3)
    - cron: '0 21 * * *'
  workflow_dispatch: # Allows manual 1-click run anytime

jobs:
  scrape-and-update:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install Playwright & Chromium
        run: |
          pip install playwright beautifulsoup4
          playwright install --with-deps chromium

      - name: Run 5-Brand Scraper (Prices + New Products Detection)
        run: python scraper_sync.py

      - name: Commit & Push Updated Catalog (Auto-Deploys to Netlify/Vercel/Pages)
        run: |
          git config user.name "SuitHub AutoSync Bot"
          git config user.email "bot@suithub.local"
          git add suits_500_tl.json
          git diff --staged --quiet || git commit -m "Auto-update TL prices & new suits at 00:00 TRT"
          git push
۳. کد کامل scraper_sync.py (بروزرسانی قیمت + تشخیص و افزودن محصولات جدید هر ۵ سایت): 
import asyncio, json, os
from datetime import datetime
from playwright.async_api import async_playwright

BRANDS = [
    {"id": "pierrecardin", "name": "Pierre Cardin", "prefix": "PC", "url": "https://www.pierrecardin.com.tr/erkek-takim-elbise/"},
    {"id": "babaterzi",    "name": "Baba Terzi",    "prefix": "BT", "url": "https://www.babaterzi.com/takim-elbise"},
    {"id": "damattween",   "name": "Damat Tween",   "prefix": "DT", "url": "https://www.damattween.com/erkek-takim-elbise-modelleri/"},
    {"id": "dsdamat",      "name": "D'S Damat",     "prefix": "DS", "url": "https://www.dsdamat.com/erkek-takim-elbise-modelleri/"},
    {"id": "sabriozel",    "name": "Sabri Ozel",    "prefix": "SO", "url": "https://www.sabriozel.com.tr/takim-elbise-42"}
]

async def sync_catalog():
    prev_db = {}
    if os.path.exists("suits_500_tl.json"):
        with open("suits_500_tl.json", "r", encoding="utf-8") as f:
            prev_db = json.load(f)

    updated_db = {"last_sync": datetime.now().strftime("%Y-%m-%d 00:00:00")}
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()

        for b in BRANDS:
            known_urls = {item["url"]: item for item in prev_db.get(b["id"], []) if "url" in item}
            await page.goto(b["url"], wait_until="domcontentloaded", timeout=60000)
            for _ in range(12):
                await page.evaluate("window.scrollBy(0, document.body.scrollHeight)")
                await asyncio.sleep(1.0)

            scraped = await page.evaluate("""() => {
                const cards = document.querySelectorAll('[class*="product"], [class*="urun"], .product-item, .product-layout');
                const out = [];
                cards.forEach((c) => {
                    const t = c.querySelector('a[title], h2, h3, .product-name, .name, .prd-name');
                    const p = c.querySelector('[class*="price"], [class*="fiyat"], .price-new');
                    const a = c.querySelector('a[href]');
                    const imgs = [...c.querySelectorAll('img')].map(i => i.dataset.src || i.currentSrc || i.src).filter(u => u && u.startsWith('http'));
                    if (t && p && imgs.length && a) {
                        out.push({
                            titleTR: (t.innerText || t.getAttribute('title') || '').trim(),
                            price_raw: p.innerText.trim(),
                            url: a.href,
                            images: [...new Set(imgs)]
                        });
                    }
                });
                return out;
            }""")

            merged = []
            for idx, item in enumerate(scraped[:100]):
                is_new = item["url"] not in known_urls
                item["code"] = f"{b['prefix']}-{101 + idx}"
                item["isNewArrival"] = is_new
                merged.append(item)

            updated_db[b["id"]] = merged

        await browser.close()

    with open("suits_500_tl.json", "w", encoding="utf-8") as f:
        json.dump(updated_db, f, ensure_ascii=False, indent=2)

asyncio.run(sync_catalog())
